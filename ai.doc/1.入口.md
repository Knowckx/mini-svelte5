# mini-svelte5 AI 入口

## 项目概况

`mini-svelte5` 是可复制使用的最小 Svelte 5 前端项目模板，当前保留 `infa-s5` 组件示例。核心技术栈为 Svelte 5、TypeScript、Vite、Tailwind CSS 4、pnpm 与 Vite PWA；当前处于模板可用阶段。

## 目录结构

- `src/`：浏览器应用源码与全局样式。
- `src/pages/`：首页和通用功能占位页。
- `src/lib/`：项目内组件；当前包含底部主导航和 PWA 更新提示。
- `public/`：PWA 图标、favicon 和静态资源。
- `vite.config.ts`：Svelte、Tailwind、HTTPS 开发服务和 PWA 配置。

## 必读文档

- [`2.当前快照.md`](2.当前快照.md)：当前功能状态、进行中事项和 TODO。
- [`3.系统架构.md`](3.系统架构.md)：运行形态、模块边界和主要数据流。
- [`4.开发约束.md`](4.开发约束.md)：修改代码时必须遵守的项目约束和可用验证命令。

## 按需读取文档

- 初始化新项目或调整启动方式：读取 `use_this_repo.md`、`package.json`、`vite.config.ts`。
- 修改应用入口、主导航或页面布局：读取 `src/App.svelte`、`src/lib/components/BottomNavigator.svelte` 和对应页面组件。
- 修改 PWA 缓存或更新流程：读取 `vite.config.ts`、`src/lib/components/PWAUpdatePrompt.svelte`。
- 修改样式或本地组件包集成：读取 `src/app.css`、`package-json.md` 和父级 `../pnpm-workspace.yaml`。

## 文档维护规则
完成开发任务后：
- 功能状态发生变化 → 更新 `2.当前快照.md`
- 系统结构发生变化 → 更新 `3.系统架构.md`
- 开发规则发生变化 → 更新 `4.开发约束.md`
- 普通代码修改无需更新架构文档
