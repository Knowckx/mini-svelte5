# 项目代码索引

## 技术栈概览

| 类别 | 技术 | 版本 |
|------|------|------|
| 框架 | SvelteKit | ^2.65.1 |
| 语言 | Svelte 5 + TypeScript | Svelte ^5.56.3 / TypeScript ^6.0.3 |
| 样式 | Tailwind CSS | ^4.3.1 |
| 构建 | Vite | ^8.0.16 |
| PWA | @vite-pwa/sveltekit | ^1.1.0 |
| 部署 | adapter-node | ^5.5.4 |

---

## 核心入口点

### 配置文件
| 文件 | 作用 |
|------|------|
| [vite.config.ts](../vite.config.ts) | Vite 构建配置，包含 SvelteKit、Tailwind、mkcert HTTPS、PWA、infa-s5 本地包处理 |
| [svelte.config.js](../svelte.config.js) | SvelteKit 配置，使用 adapter-node 部署 |
| [package.json](../package.json) | 项目依赖和脚本命令 |

### 应用入口
| 文件 | 作用 |
|------|------|
| [src/app.html](../src/app.html) | HTML 模板入口，包含移动端视口、PWA 图标和基础 meta |
| [src/routes/+layout.svelte](../src/routes/+layout.svelte) | 全局布局，导入全局样式、favicon、PWA 更新提示和 infa-s5 Toast UI |
| [src/routes/+page.svelte](../src/routes/+page.svelte) | 首页，演示 infa-s5 Button/Tip 用法，并提供 File System Access API 测试页入口 |
| [src/routes/+page.ts](../src/routes/+page.ts) | 首页路由配置，当前启用 prerender |
| [src/routes/file-system-access/+page.svelte](../src/routes/file-system-access/+page.svelte) | File System Access API 教学测试页，覆盖读文件、选目录、写文件、删除、OPFS |

## 项目结构

```
mini-svelte5/
├── src/
│   ├── app.d.ts                    # TypeScript 类型声明

│   │   ├── index.ts                # 库入口

│   │   │   ├── PWAUpdatePrompt.svelte  # PWA 更新提示组件
│   │   │   └── ui/                 # shadcn-ui 组件 (空)
│   │   ├── config/                 # 配置
│   │   │   └── index.ts            # 配置入口
│   │   ├── hooks/                  # 自定义 hooks (空)
│   │   ├── stores/                 # Svelte stores (空)
│   │   ├── styles/                 # 样式文件 (空)
│   │   ├── types/                  # 类型定义 (空)
│   │   └── utils/                  # 工具函数

│   │       └── cn.ts               # Tailwind class 合并工具
│   └── routes/                     # 路由页面
│       ├── +layout.svelte          # 全局布局
│       ├── +page.svelte            # 首页

│           └── README.md           # 教学目标和实现说明

│   ├── pwa-512x512.png             # PWA 图标

│   └── robots.txt                  # 爬虫配置

│   ├── 01 开发背景信息.md          # 项目说明和代码规范
│   ├── 02 项目进度.md              # 开发计划和进度
│   └── 03 项目代码索引.md          # 本文件
├── vite.config.ts                  # Vite 配置
├── svelte.config.js                # SvelteKit 配置
├── tsconfig.json                   # TypeScript 配置
├── components.json                 # shadcn-ui 配置
└── package.json                    # 依赖管理
```

## 关键依赖

### 核心依赖 (dependencies)
| 包名 | 作用 |
|------|------|
| `infa-s5` | 本地 UI 组件库，当前通过 `workspace:*` 引用，项目中保留 `.yalc` 本地包痕迹 |
| `mode-watcher` | 深色/浅色模式切换 |
| `svelte-sonner` | Toast 通知组件 |

### 开发依赖 (devDependencies)
| 包名 | 作用 |
|------|------|
| `@vite-pwa/sveltekit` | PWA 支持 |
| `vite-plugin-mkcert` | 本地 HTTPS 证书 |
| `@lucide/svelte` | 图标库 |
| `tailwind-variants` | Tailwind 变体工具 |

## 开发命令

```bash
pnpm dev      # 启动开发服务器 (https://localhost:23001)
pnpm build    # 生产构建
pnpm preview  # 预览生产构建 (http://localhost:33001)
```
