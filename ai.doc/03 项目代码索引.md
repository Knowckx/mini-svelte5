# 项目代码索引

## 技术栈概览

| 类别 | 技术 |
|------|------|
| 框架 | Svelte 5 |
| 构建 | Vite |
| 语言 | TypeScript |
| 样式 | Tailwind CSS 4 |
| UI | infa-s5 / shadcn-svelte 配置 |
| 本地 HTTPS | vite-plugin-mkcert |

---

## 核心入口点

### 配置文件

| 文件 | 作用 |
|------|------|
| [vite.config.ts](../vite.config.ts) | Vite 配置，包含 Svelte、Tailwind、mkcert、`$lib` alias、`infa-s5` 本地包处理 |
| [tsconfig.json](../tsconfig.json) | TypeScript 配置，手动维护 `$lib` alias，不依赖 SvelteKit 生成配置 |
| [package.json](../package.json) | 项目依赖和脚本命令 |
| [components.json](../components.json) | shadcn-svelte 配置 |

### 应用入口

| 文件 | 作用 |
|------|------|
| [index.html](../index.html) | Vite HTML 入口 |
| [src/main.ts](../src/main.ts) | 挂载 Svelte 应用 |
| [src/App.svelte](../src/App.svelte) | 应用壳，注册 `infa.Tip.UI`，用轻量前端路由切换页面 |
| [src/app.css](../src/app.css) | 全局 Tailwind 样式、主题变量、`infa-s5` 样式扫描 |
| [src/pages/HomePage.svelte](../src/pages/HomePage.svelte) | 首页，演示 `infa-s5` Button/Tip，并提供 File System Access 页面入口 |
| [src/pages/FileSystemAccessPage.svelte](../src/pages/FileSystemAccessPage.svelte) | File System Access API 教学测试页，覆盖读文件、选目录、写文件、删除、OPFS |

---

## 项目结构

```
mini-svelte5/
├── index.html                      # Vite HTML 入口
├── src/
│   ├── main.ts                     # Svelte 应用挂载入口
│   ├── App.svelte                  # 应用壳和轻量前端路由
│   ├── app.css                     # 全局样式
│   ├── app.d.ts                    # Vite 类型引用
│   ├── lib/                        # 库代码 ($lib 别名)
│   │   ├── index.ts                # 库入口
│   │   ├── assets/                 # 静态资源
│   │   │   └── favicon.svg         # 网站图标
│   │   ├── components/             # 组件目录
│   │   │   └── ui/                 # shadcn-ui 组件目录
│   │   ├── config/                 # 配置
│   │   │   └── index.ts            # 配置入口
│   │   ├── hooks/                  # 自定义 hooks
│   │   ├── stores/                 # Svelte stores
│   │   ├── styles/                 # 样式文件
│   │   ├── types/                  # 类型定义
│   │   └── utils/                  # 工具函数
│   │       ├── index.ts            # 工具入口
│   │       └── cn.ts               # Tailwind class 合并工具
│   └── pages/                      # 普通页面组件
│       ├── HomePage.svelte         # 首页
│       ├── FileSystemAccessPage.svelte        # File System Access 教学页
│       └── FileSystemAccessPage.README.md     # 教学说明
├── static/                         # 静态文件
│   ├── pwa-512x512.png             # 图标资源
│   ├── placeholder-1024.png        # 占位图资源
│   └── robots.txt                  # 爬虫配置
├── ai.doc/                         # AI 文档
│   ├── 01 开发背景信息.md          # 项目说明和代码规范
│   ├── 02 项目进度.md              # 开发计划和进度
│   └── 03 项目代码索引.md          # 本文件
├── vite.config.ts                  # Vite 配置
├── tsconfig.json                   # TypeScript 配置
├── components.json                 # shadcn-svelte 配置
└── package.json                    # 依赖管理
```

## 关键依赖

### dependencies

| 包名 | 作用 |
|------|------|
| `infa-s5` | 本地 UI 组件库，当前通过 `workspace:*` 引用，项目中保留 `.yalc` 本地包痕迹 |
| `mode-watcher` | 深色/浅色模式切换 |
| `svelte-sonner` | Toast 通知组件 |

### devDependencies

| 包名 | 作用 |
|------|------|
| `@sveltejs/vite-plugin-svelte` | Vite 的 Svelte 插件 |
| `@tailwindcss/vite` | Tailwind CSS 4 的 Vite 插件 |
| `vite-plugin-mkcert` | 本地 HTTPS 证书 |
| `@lucide/svelte` | 图标库 |
| `tailwind-variants` | Tailwind 变体工具 |

## 开发命令

```bash
pnpm dev      # 启动开发服务器 (https://localhost:23001)
pnpm build    # 生产构建
pnpm preview  # 预览生产构建 (http://localhost:33001)
```
