# 系统架构

## 技术栈与运行形态

- 浏览器端单页应用：Svelte 5、TypeScript 6、Tailwind CSS 4。
- 构建与开发：Vite 8、pnpm；开发服务通过 `vite-plugin-mkcert` 启用 HTTPS。
- PWA：`vite-plugin-pwa`、Workbox 和浏览器 Service Worker。
- UI 依赖：父级 pnpm 工作区中的 `@knowckx/infa-s5`。
- 当前没有 URL 路由、服务端、数据库或远程 API 集成。

运行链路：`index.html` → `src/main.ts` → `App.svelte` → `infa-s5/BottomNavigator` → 当前页面组件

## 核心模块与边界

- `src/main.ts`：加载全局样式并挂载根组件。
- `src/App.svelte`：配置四个主页面和中央 FAB，并挂载全局消息 UI 与项目级 PWA 更新控制器。
- `@knowckx/infa-s5` 的 `BottomNavigator`：维护主导航状态、缓存恢复、动态页面渲染和 scoped CSS 底部五列布局。
- `src/pages/HomePage.svelte`：提供可选顶部导航、一级 Tab、滚动内容区和 `infa-s5` 使用示例。
- `src/pages/FeaturePage.svelte`：功能1至功能3复用的轻量占位页。
- `src/lib/components/PWAUpdateController.svelte`：注册 Service Worker、轮询更新、执行新版本应用与刷新策略。
- `@knowckx/infa-s5` 的 `PWAUpdatePrompt`：使用 scoped CSS 展示离线就绪、发现更新、更新中和错误状态。
- `vite.config.ts`：统一配置编译插件、路径别名、开发/预览服务和 PWA 清单与缓存规则。

## 主要调用链与数据流

主导航：点击底部 Tab 或外部修改 `bottomNavigationState.activeLabel` → 校验 label → 动态渲染页面 → 写入 `localStorage`

页面布局：当前页面可选顶部导航 → 页面内容独立滚动 → 底部主导航固定显示

PWA 更新：Service Worker 注册 → 每 60 秒检查更新 → Controller 转换状态 → 公共 Prompt 展示 → 用户确认 → 应用新 Worker → 页面刷新

## 内部依赖与外部系统

- 项目由父级 `../pnpm-workspace.yaml` 纳入工作区；`@knowckx/infa-s5` 使用 `workspace:*` 解析。
- `@` 在 `tsconfig.json` 和 `vite.config.ts` 中均指向 `src/`。

## 存储与部署

- 业务模板自身没有持久化数据层。
- `pnpm build` 生成 Vite 静态产物；`pnpm pwa` 构建后以 Vite Preview 提供访问。
